FAQ

Frequently asked questions

Is Northstar Bank a real bank?

No. Northstar Bank is a fictional frontend banking demonstration. It does not provide real banking services or process real transactions.

Can I create a real account?

No. Registration is simulated locally in the demo and does not create a real financial account.

Are the demo login credentials real?

No. The credentials supplied with this project are fictional demonstration credentials only.

How do I access the customer portal?

Use the Sign in page and enter the fictional customer demo credentials provided with the project.

Security

Security is built into the demo experience.

This frontend demonstrates interface patterns only. A production banking system would require secure backend authentication, authorization, encryption, session controls, MFA, rate limiting, fraud monitoring, audit logging, and regulatory controls.
